# Gundaveni Prasanna - Personal Portfolio Website

A personal portfolio website for **Gundaveni Prasanna**, B.Tech 4th-year student, showcasing technical competencies across frontend web technologies, Python, and SQL.

## 🌿 Overview
- **Aesthetics:** Alice Green-inspired color system with glassmorphism surfaces and dark/light theme switching.
- **Technologies Used:** Semantic HTML5, CSS3 Custom Properties, and Vanilla JavaScript. Zero external frameworks or heavy libraries.
- **Featured Project:** NPK-Based Fertilizer Recommendation System.
- **Responsive:** Optimized for desktops, tablets, and smartphones.

## 🚀 Project Structure
```text
myportfolio/
├── index.html       # Semantic page layout, accessibility landmarks & sections
├── style.css        # Alice Green color system, dark theme, and animations
├── script.js        # Theme toggle, mobile menu, scroll reveals & contact handling
├── .gitignore       # Git ignore rules
└── README.md        # Project documentation
```

## 💻 How to Run Locally
1. Clone or download this repository:
   ```bash
   git clone https://github.com/prasannagundaveni/myportfolio.git
   ```
2. Open the folder in **VS Code**.
3. Right-click `index.html` and select **"Open with Live Server"**, or open `index.html` directly in any modern browser.
